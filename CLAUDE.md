# Читалка — iOS-читалка с постепенным переводом слов на английский

Читатель открывает русскую книгу и крутит кольцо: на 10% каждое десятое слово в тексте
заменяется английским. Мозг достраивает смысл из контекста; не достроил — тап по слову
показывает перевод. Приложение работает полностью офлайн.

Пример на 12%: «Сегодня **morning** я встал с **bed**, чтобы пойти в сад за **apples**.»

## Состояние проекта

Перенесено с Windows на Mac, собрано и запущено в симуляторе.

| Часть | Состояние |
|---|---|
| `Core/` — Swift Package с логикой перевода | Собирается, 50 тестов зелёные |
| `Core/Tests/.../Fixtures/golden_plan.json` | Эталон, сгенерирован независимой реализацией на Python |
| `App/` — SwiftUI-исходники | Компилируется, приложение работает: импорт, полка, чтение, подмена слов |
| `tools/` — сборка словаря | Работает |
| `Data/ru-en.sqlite` | Настоящий словарь: 47 489 лемм, 43,5 МБ. Собирается `tools/build_dictionary.py` |
| `design/mockup.html` | Утверждённый дизайн, рабочий прототип логики в браузере |
| Xcode-проект | Генерируется из `App/project.yml`: `cd App && xcodegen generate` |

Не сделано: пагинация на TextKit 2 (страница режется по знакам), кольцо пальцем,
StoreKit, проверка импорта на реальных EPUB/FB2. Список — в конце `docs/ROADMAP.md`.

## Порядок работы на Mac

Всё по шагам — в [README.md](README.md). Коротко: собрать словарь (`tools/`),

## Архитектура

```
Текст книги
   │
   ├─ Tokenizer ──────── слова + смещения в UTF-16 (для TextKit)
   ├─ Lemmatizer ─────── кровати → кровать   (NLTagger, встроен в iOS)
   ├─ WordDictionary ─── кровать → bed       (SQLite в бандле)
   ├─ CandidateRanker ── фиксированный порядок: что переводить первым
   └─ TranslationPlan ── срез первых N кандидатов, где N = процент × число слов
```

Ключевое свойство: **порядок кандидатов фиксирован и не зависит от процента.**
Отсюда бесплатно следует, что план на 10% содержит в себе весь план на 5% — текст
не перетасовывается, когда читатель крутит кольцо. Это проверяется тестом
`testMonotonicity`, и его нельзя ломать.

Подробнее — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Решения, которые не пересматриваются

Приняты заказчиком до начала работы. Полный список с обоснованиями —
[docs/DECISIONS.md](docs/DECISIONS.md). Кратко:

- Процент считается **от всех слов текста**, не от переводимых.
- Кольцо **0–100%**, нелинейное: 0–60% занимают 3/4 оборота.
- **Рекламы нет.** После триала — 10 страниц в день бесплатно.
- **£4.99 разовой покупкой**, не подписка. Триал 3 дня.
- Первый релиз — **только русский**. Украинский вторым.
- **PDF не поддерживаем.** EPUB, FB2, TXT.
- Словари только со свободной лицензией. **GPL-источники запрещены** — конфликт с App Store.
- На карточке книги: кольцо = доля перевода, полоса = прочитано.

## Конвенции

- Swift 5.9+, iOS 17+. SwiftUI, SwiftData, StoreKit 2.
- `Core` не импортирует SwiftUI и UIKit. Он должен собираться и тестироваться
  сам по себе через `swift test`, без Xcode и без симулятора.
- `Core` не зависит от `NaturalLanguage` жёстко: лемматизатор спрятан за протоколом,
  реализация на NLTagger подключается через `#if canImport(NaturalLanguage)`.
- **Нельзя использовать `Hasher` и `hashValue` для отбора слов.** Swift рандомизирует
  их между запусками — план перевода станет разным при каждом открытии книги.
  Только `StableHash` (FNV-1a) из `Core`.
- Комментарии в коде и тексты интерфейса — по-русски. Имена типов и переменных — по-английски.
- Пользователь общается по-русски; отвечать ему по-русски.

## Команды

```bash
cd Core && swift test                          # тесты логики, работают без Xcode
cd App && xcodegen generate                    # пересобрать Xcode-проект из project.yml
python3 tools/build_dictionary.py --sample     # словарь-затравка, секунда, без сети
python3 tools/build_dictionary.py              # настоящий словарь, 10–40 минут
python3 tools/make_golden.py                   # перегенерировать эталон
```

`make_golden.py` запускать только если алгоритм отбора менялся сознательно.
Если `testMatchesGoldenFixture` покраснел сам по себе — чинить надо код, а не эталон.
