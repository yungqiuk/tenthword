## После первого релиза

Решение от 23 августа 2026: 1.0 выходит только с русским интерфейсом и русскими
книгами. Правки после первой публикации проходят ревью быстрее и придирок к ним
меньше. Оговорка: новый язык интерфейса — это всё равно новая сборка и новое
ревью; бесплатно добавляются только локализации карточки в App Store.

- **Локализация интерфейса (uk, en).** 114 строк, работа механическая: SwiftUI
  локализует строковые литералы сам, как только появится каталог строк.
  Руками надо переписать те места, где текст лежит в обычной `String` и потому
  не локализуется: ошибки в `PurchaseStore`, названия тем и шрифтов в `Theme`,
  надпись над заголовком в `PaywallView`, ярлыки частей речи и зон кольца
  в `Core`. **Отдельно:** кнопки цены в `SettingsView` и `PaywallView` собраны
  через `store.displayPrice.map { … } ?? …`, то есть дают `String` вместо
  `LocalizedStringKey` — при локализации они молча останутся русскими.
  Сегодня это ни на что не влияет: интерфейс и так русский. День работы.
- Украинский языковой пакет: морфология, словарь, 2–3 недели. Главное
  препятствие — у Apple нет лемматизатора для украинского
  (`NLTagger.availableTagSchemes` для `uk` не содержит `.lemma`, проверено).
  Значит, лемматизация целиком ложится на таблицу «форма → лемма»
  из Викисловаря; словарь вырастет на десятки мегабайт.
- Множественное число: `яблоками → apples`, а не `apple`
- Падежи для предлогов вместо частотных вариантов
- Синхронизация полки и позиции чтения через CloudKit
- iPad: две колонки, боковая панель
