## Что делать прямо сейчас

Ядро, словарь и проект готовы, приложение запускается и переводит. Дальше по важности:

1. **Пагинация на TextKit 2.** Сейчас страница режется по 1800 знаков с привязкой
   к абзацам — этого хватило, чтобы книга на 600 КБ вообще нарисовалась, но страница
   не считается по высоте экрана и не держит позицию при смене шрифта.
2. **Просмотреть верхнюю тысячу слов по частотности.** Машинный разбор Викисловаря
   шумит: многословные эквиваленты («ждать» → *wait for*, «утром» → *in the morning*),
   неудачный выбор первого термина. Решить заодно, подставлять ли многословные вообще.
3. **Кольцо пальцем и тактильная отдача** — пересчёт уже мгновенный (0,6 мс),
   осталась сама жестикуляция.
4. **Проверить импорт на пяти реальных книгах** EPUB/FB2 — код разбора ни разу
   не встречался с настоящим файлом.
